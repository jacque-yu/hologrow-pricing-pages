# Hologrow pricing pages

Public static HTML for the Chinese and English Hologrow pricing pages. Published through GitHub Pages from `main` / `docs`.

- [中文定价](https://jacque-yu.github.io/hologrow-pricing-pages/pricing-zh.html)
- [English pricing](https://jacque-yu.github.io/hologrow-pricing-pages/pricing-en.html)

The contact-sales pages are included for navigation. Their forms are display-only until a submission service is connected.

To refresh from the validated source build, start its local production preview on port 3092, install dependencies, and run `HOLOGROW_SOURCE_DIR=/path/to/source node export.mjs`. Review generated pages before publishing. Only approved public page HTML and referenced local assets are exported; the application source and private configuration are not included.

The repository is owned by [jacque-yu](https://github.com/jacque-yu/hologrow-pricing-pages). These are fixed GitHub Pages URLs with no scheduled expiration; they remain available while this repository and GitHub Pages stay enabled. Chinese and English pages have matching language links, page-specific metadata, and a [localized sitemap](https://jacque-yu.github.io/hologrow-pricing-pages/sitemap.xml).
